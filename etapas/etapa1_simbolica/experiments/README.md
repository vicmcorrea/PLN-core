# experimentos da etapa 1

Esta pasta registra os experimentos simbolicos que precisam aparecer no relatorio da etapa 1.

Resultados gerados automaticamente devem ficar em `../../outputs/etapa1_symbolic/`, que nao entra no Git. Quando um resultado for aprovado para o relatorio, registre aqui a configuracao usada, o caminho do JSON e um resumo curto das metricas.

Experimentos minimos:

1. `oplexicon` no teste Kaggle multiclasse.
2. `oplexicon_tweet` no teste Kaggle multiclasse.
3. `majority` como baseline simples.
4. `sample` apenas como smoke test de regressao.
